> [!TIP]
> Press `1` to change the **background colour**
> 
> Press `F11` to go into **fullscreen**

### To download locally:
1. Click the green `Code` drop-down and select `Download ZIP`
2. Once downloaded, extract the ZIP file
3. Open one of the `bsod.html` files
